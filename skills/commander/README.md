# Commander

Commander is a Herdr-native supervisor skill for AI-agent fleets. It runs
inside Herdr (`HERDR_ENV=1`), monitors panes through the Commander watcher
plugin, learns approval rules from Captain decisions, queues unknown blocks
for review, and delegates work to crewmates.

On Windows, run `herdr` commands through PowerShell. See
[SKILL.md](SKILL.md) for operating instructions and
[references/herdr-commands.md](references/herdr-commands.md) for CLI usage.
